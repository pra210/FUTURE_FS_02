🛍️ Mini E-Commerce Store (React)

This project is a *Mini E-Commerce web application* developed using *React* as part of my internship task.  
The goal of this project is to understand *real-world frontend concepts* such as state management, routing, component reuse, and UI layout.

Unlike a simple demo, this app simulates a basic shopping flow — from browsing products to checkout.

---

✨ What Makes This Project Special?

- Designed and built *from scratch* using React
- Clean and user-friendly UI with a blue & white theme
- Uses *React Context API* for global cart state
- Real-time cart updates without page reload
- Search functionality to filter products instantly
- Structured codebase following industry practices

---

🔍 Features Overview

- 🔐 Login page (UI based authentication flow)
- 🏠 Home page with product listing
- 🔎 Search bar to filter products
- 🛒 Add to Cart functionality
- 📦 Cart summary with total price calculation
- 💳 Checkout page with Pay Now option
- ♻️ Reusable and modular components

---

 🧠 Concepts Used

- React Functional Components
- React Hooks (useState, useContext)
- React Router for navigation
- Context API for global state
- Conditional rendering
- Component-based architecture
